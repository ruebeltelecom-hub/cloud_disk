# Облачный Диск — приложение для iOS

Мобильное приложение **«Облачный Диск»** для iOS — облачный сервис хранения файлов, фотографий и документов РУП «Белтелеком».

Приложение является брендированной сборкой на основе открытого клиента **[Nextcloud iOS](https://github.com/nextcloud/ios)**.
